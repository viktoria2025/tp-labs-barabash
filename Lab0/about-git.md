Ветка - это легковесный указатель, а не копия папки. В Git ветка это просто указатель на коммит, её создание почти мгновенно и не дублирует файлы проекта. 
Копирование всей папки, напротив, занимает место и требует времени на физическое дублирование файлов.

История сохранится полностью. Вся история коммитов, ветки и теги хранятся внутри .git. Рабочая папка это лишь «проекция», 
которую можно восстановить из .git в любой момент. Пропадут только незакоммиченные изменения.

Для контроля качества и безопасности. Pull Request позволяет провести код-ревью, обсудить изменения построчно и запустить автоматические
проверки (тесты, сборка) до того, как код попадёт в main. Это защищает основную ветку от ошибок и даёт прослеживаемую историю изменений.
